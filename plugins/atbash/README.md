# Atbash Safety

This package is the plugin payload for the Git-backed Atbash marketplace. It contains the Claude Code plugin manifest, catch-all `PreToolUse` hook, `atbash-setup` skill, compiled SDK adapter, and a committed universal runtime with every native platform binding published for `@atbash/sdk@0.6.2`. It does not require an MCP server or upload user credentials to one.

Use the repository root for installation, configuration, testing, and security guidance.
